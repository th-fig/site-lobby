Projetos de Eletrônica

Semáforo

Clássico projeto de iniciante em Arduino porém com detalhes a mais, adicionei um semáforo para pedestres além de um display de 7 segmentos para cronometrar o tempo restante para o pedestre atravessar a rua. Os links para baixar o código e acessar ele no simulador do Tinkercad estão abaixo.

Link do GitHub: /semaforo

Link do Tinkercad: /semaforo

Contador Infravermelho

Um projeto mais avançado que utiliza Arduino, sensor infravermelho e display LCD com interface I2C. O sistema exibe um contador que pode ser incrementado, decrementado ou resetado remotamente por meio do sensor infravermelho.

Link do GitHub: /contador-infravermelho

Link do Tinkercad: /contador-infravermelho

Servo Potenciômetro

Um projeto clássico para quem utiliza Arduino, no qual um potenciômetro é usado para controlar a posição de um servo motor. Além disso, o sistema exibe em um display LCD-I2C a posição atual do servo em tempo real.

Link do GitHub: /servo-potenciometro

Link do Tinkercad: /servo-potenciometro

Sensor de Proximidade

Um projeto que utiliza um sensor ultrassônico para ligar e desligar um LED, ao aproximar um objeto a uma distância menor que o mínimo de ativação conta-se um tempo e o modo do LED se altera. Para o bem da sua sanidade mental não tente entender como o código funciona, apenas aceite que ele funcione.

Link do GitHub: /sensor-proximidade

Link do Tinkercad: /sensor-proximidade
